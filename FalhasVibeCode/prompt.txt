Crie um aplicativo em Python com Streamlit que funcione como um chat simples com IA. Requisitos: Usar a biblioteca Streamlit, usar a API da OpenAi via from openai import OpenAI, carregar a chave de ambiente com python-dotenv (load_dotenv), criar o cliente com OpenAI (api_key=os.getenv("OpenAi_Key")), interface com st.chat_imput e st.chat_message, manter histórico da conversa em st.session_state ["Mensagens"], iniciar o histórico com um system prompt dizendo que é um assistente de loja online, enviar todo o histórico para client.chat.completions.create, exibir resposta da IA na tela e salvar no histórico, código competo em um único arquivo app.py, manter o cóodigo simples e direto como eu citei e com poucas linhas. O app deve se chamar "ShopAi" e simular uma loja online com IA no atendimento ao cliente. Interface simples e minimalista.
